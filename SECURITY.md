# Security policy

Please report security issues privately by e-mail to **support@ramzx.de**
(not as a public GitHub issue). Include the RamzX OTP version, the steps to reproduce and,
if possible, a test file or QR code – never real secrets.

We answer within a few working days and publish a fix and a note in the release once the
issue is resolved.

Supported versions: the latest release.
